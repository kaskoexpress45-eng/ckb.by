Проверяемый опубликованный адрес, указанный владельцем: https://ckb-by.vercel.app/. Дата: 20 октября 2026.

## Подтверждённая причина неактивной заявки

На опубликованной главной HTML содержит `<button type="submit" disabled>`: это отключённый приём, а не невозможность попасть пальцем по кнопке. Ключи интеграций отсутствуют; имитация успешной отправки не добавлена. Пока интеграции не включены, посетитель пользуется реальными прямыми контактами.

## Telegram

Опубликованный адрес ссылки — https://t.me/yuribelchik, Telegram отвечает HTTP 200. Мобильный Chromium (390px, touch) открыл этот адрес по нажатию из опубликованного блока формы. Для чтения опубликованного HTML, CSS и JS использован локальный relay с проверенным HTTPS через системный TLS, поскольку Chromium не доверяет сертификату прокси среды. Сам Telegram-переход перехвачен тестом: приложение и отправка сообщения не проверялись. Новая версия использует официальный HTTPS-адрес с параметром text для черновика. Сайт ничего не отправляет от имени посетителя.

## Итоговый путь

Готов к разговору: первый экран → «Обсудить задачу» → Telegram/email.
Нужна конкретная помощь: карточка задачи или формат → обращение с сохранённым выбором → черновик сообщения.
Нужно разобраться: «Выбрать тему работы» → задачи → форматы/подход → обращение.
Страхование и накопления: соответствующая страница → тематическое обращение.

Нажатие Telegram — переход к контакту, а не подтверждённая заявка. Рост конверсии без измерений не заявляется. Реальное открытие Telegram проверяется на устройстве владельца после публикации.

## Публикация и повторная проверка
Vercel сообщил успешную автоматическую публикацию коммита 095b70c на ckb-by.vercel.app. Повторная проверка опубликованных HTML/CSS/JS через системный TLS relay: при 320 и 390 px на главной и контактах неактивной формы нет; настоящие нажатия Telegram-кнопки инициируют переход к t.me/yuribelchik с черновиком, а на странице выбранного корпоративного тренинга название сохранено. Навигация Telegram перехвачена до внешнего ответа, сообщения не отправлялись. Скриншоты published-disabled-form-mobile.png и published-fixed-mobile.png показывают до/после.
